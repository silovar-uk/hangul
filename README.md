# ハングル・クエスト

カタカナを手がかりに、ハングルの「読み」だけをゲーム感覚で練習する静的Webアプリです。

## 特徴

- ハングル → カタカナ、カタカナ → ハングル、ミックス出題
- 基本母音から短い単語まで8ステージ
- 5問クエスト、10問ステージ、苦手つぶし
- スコア、コンボ、集中ゲージ、経験値、ステージ解放
- 誤答と回答速度を使った弱点優先出題
- 学習記録は `localStorage` に保存
- 音声、ログイン、外部通信なし

## ローカル実行

```bash
npm run serve
```

ブラウザで `http://localhost:4173` を開いてください。

## テスト

```bash
npm test
npm run check
```

## 公開

`main` ブランチへのpushで、GitHub ActionsからGitHub Pagesへデプロイします。

## 学習上の注意

カタカナ表記は発音の目安です。まず文字を識別して読めるようになることを目的とし、正確な発音や音変化は今後の学習段階で扱う想定です。
