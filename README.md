# ハングル・クエスト

ハングルの文字読みから、単語・フレーズの意味まで段階的に練習する静的Webアプリです。

## 特徴

- ハングル → カタカナ、カタカナ → ハングル、ミックス出題
- 基本母音から短い単語まで8ステージ
- 単語46件、フレーズ27件を収録
- 単語・フレーズは「意味 ↔ カタカナ」→「意味 ↔ ハングル」→「ミックス」の3段階
- 一覧表は検索・カテゴリ絞り込み・単語帳保存に対応
- 単語帳は「すべて／保存／苦手／未学習」で復習可能
- 5問クエスト、10問ステージ、苦手つぶし
- スコア、コンボ、集中ゲージ、経験値、ステージ解放
- 誤答と回答速度を使った弱点優先出題
- 学習記録は `localStorage` に保存
- 音声、ログイン、外部通信なし

## ローカル実行

```bash
npm run serve
```

ブラウザで `http://localhost:4173` を開いてください。

## テスト

```bash
npm test
npm run check
```

## 公開

`main` ブランチへのpushで、GitHub ActionsからGitHub Pagesへデプロイします。

## 学習上の注意

カタカナ表記は発音の目安です。まず文字・読み・意味を結びつけることを目的とし、正確な発音や音変化は別の学習段階で扱う想定です。
